# mattrivo

Premium mattress e-commerce homepage for the UK market. Next.js (App Router), React, TypeScript, Tailwind CSS v4, Framer Motion and Lucide.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

## What is on the page

Header with mega menus, search, account, wishlist and basket · Hero · Trust strip · Collections (filters the product grid) · Bestsellers with filtering, quick view, compare and add to basket · Mattress Finder (8 questions, rule-based results) · Interactive exploded mattress construction · Sleeping styles · Lifestyle gallery · 90-night trial · Three-range comparison · Brand values · Reviews carousel · Materials & sustainability · Sleep Journal · FAQ · Closing CTA · Footer with newsletter.

Also included: product pages (`/mattresses/[slug]`), journal articles (`/journal/[slug]`) and placeholder legal/contact pages (`/info/[slug]`).

## Editing content

All content lives in `src/data`, separate from the UI:

| File | What it holds |
| --- | --- |
| `products.ts` | Products, demonstration prices per UK size, firmness, depth, attributes used by the Finder |
| `ranges.ts` | The three-range comparison table |
| `mattressLayers.ts` | Construction layers, descriptions and material notes |
| `finder.ts` | Mattress Finder questions and options |
| `reviews.ts` | **Sample reviews (demo content)**, to be replaced with verified reviews |
| `faqs.ts` | FAQ copy |
| `articles.ts` | Sleep Journal articles |
| `content.ts` | Collections, sleeping styles, brand values, materials topics |
| `site.ts` | Business settings and policies (trial, delivery, returns, warranty, VAT, payments) |
| `navigation.ts` | Header and footer navigation |

### Unconfirmed information

Nothing unverified is presented as fact. In copy, wrap anything awaiting confirmation in double braces, for example `"Delivery takes {{to be confirmed}}"`. It renders as a highlighted placeholder (`PolicyText` component) until you replace it. Prices, specifications, the trial, warranty and reviews are all labelled as demonstration or proposed values.

## How things work

- **Recommendations** (`src/lib/recommendation.ts`): transparent scoring against product attributes. Every point awarded can produce a plain-English reason. No percentages are shown.
- **State** (`src/lib/store.tsx`, `src/hooks/*`): basket, wishlist and comparison persist in `localStorage`. Checkout deliberately stops before payment so it can be connected to Shopify, WooCommerce or a custom backend.
- **Mattress artwork** (`src/components/mattress/art.tsx`): an axonometric SVG system. Each face has its own coordinate space, so material textures foreshorten correctly. The exploded view renders each layer as its own GPU-composited element. Product images are rendered from the same system, using each product's depth and finish.
- **Textures** (`public/textures`) are generated by `python3 scripts/generate-textures.py` (Pillow only).
- **Motion** respects `prefers-reduced-motion` via `MotionConfig reducedMotion="user"`.

## Testing

`scripts/e2e.mjs` drives the main interactions in Chrome (menus, search, basket, wishlist, compare, quick view, Finder, construction view, FAQ, newsletter, pages, mobile menu, overflow checks at 375–1280 px):

```bash
npm run build && npx next start -p 3200
node scripts/e2e.mjs http://localhost:3200
```

It uses `playwright-core` with the locally installed Google Chrome.
